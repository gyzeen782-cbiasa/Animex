📦 Setup JSONBin.io
Data anime upload disimpan di JSONBin (gratis). Daftar di jsonbin.io, buat bin baru, lalu isi info di bawah.
📖 Cara Setup JSONBin
  1. Buka jsonbin.io → Sign Up gratis
  2. Klik New Bin → isi JSON: {"animes":[]}
  3. Copy Bin ID dari URL: jsonbin.io/b/[BIN_ID]
  4. Ke Settings → API Keys → buat key baru
  5. Isi keduanya di form atas → Simpan
🛡️ Keamanan

Password admin disimpan di browser. Jangan gunakan password yang sama dengan akun penting. Halaman admin bisa diakses di admin.html — sembunyikan dari publik jika perlu.
